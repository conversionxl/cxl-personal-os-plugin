# team-updates/

Standup-format status updates built from your daily logs, named `week-of-YYYY-MM-DD.md` for a week or `YYYY-MM-DD.md` for a single day.

- A session-start hook writes last week's update automatically if it does not exist yet.
- `/personal-os:team-update` writes one for any period, and lets you review and edit it first.
